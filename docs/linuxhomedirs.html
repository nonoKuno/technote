Ubuntuのホームディレクトリ名を英語に変更する

公開日: 2025年9月4日 読了時間: 約5分
Linux CLI

xdg-user-dirs-gtk-updateを利用し、ロケールに基づいたディレクトリ名を更新する手順である。

1. 実行コマンド

以下のコマンドをターミナルで実行することで、ディレクトリ名を英語（LANG=Cロケール）に更新するプロンプトが表示される。

LANG=C xdg-user-dirs-gtk-update

2. コマンド解説

LANG=C

コマンド実行時における環境変数LANGを一時的にC（POSIX標準ロケール）に設定する。これにより、後続のコマンドは英語環境で動作する。

xdg-user-dirs-gtk-update

freedesktop.orgのXDG Base Directory Specificationに基づき、ユーザーの特殊ディレクトリ（DESKTOP, DOWNLOADSなど）のパスを管理するツールである。現在のロケール設定（この場合はC）を~/.config/user-dirs.localeと比較し、差異があれば設定ファイル~/.config/user-dirs.dirsの更新をGUIダイアログでユーザーに提案する。

3. 実行フロー

  1. コマンド実行後、GTKダイアログが表示される。
  2. ダイアログには、現在のディレクトリ名（例: ~/ダウンロード）と新しいディレクトリ名（例: ~/Downloads）の対応リストが表示される。
  3. "Update Names" ボタンをクリックすると、~/.config/user-dirs.dirsが更新され、新しいディレクトリが作成される。
  4. 変更をシステム全体に反映させるため、再ログインが推奨される。

4. 日本語への復元

日本語ロケール環境でLANG=Cを付与せずに同じコマンドを実行すると、日本語ディレクトリ名に戻すためのダイアログが表示される。

xdg-user-dirs-gtk-update
Note: ディレクトリ内にファイルが存在する場合、元のディレクトリは削除されずに残る。必要に応じて手動でファイルを新しいディレクトリに移行すること。
